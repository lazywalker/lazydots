Launcher & Session
Super+Return	Terminal

Super+Shift+B	Browser
Super+D	App launcher
Super+Alt+D	Run command
Super+Alt+P	Power menu
Super+Alt+Ctrl+L	Lock screen
Super+Shift+P	Turn off monitor

Window
Super+Shift+Q	Close window
Alt+R	Resize window

Workspaces

Super+G/B	Prev/next workspace
Super+X	Previous workspace

App Actions
Super+C	Copy (context)
Super+V	Paste (context)
