# Dotfiles

Personal Linux desktop dotfiles on Arch Linux. Manages a Wayland-centric
desktop environment with Hyprland as the primary compositor and Niri / Sway as
alternatives. FVWM3 is kept as an X11 option.

The `~/.config` directory **is** the git repository — no symlink manager
(stow / chezmoi) is used. Changes to tracked files are immediately live.

## Compositor layer

| Compositor | Config | Shell |
|------------|--------|-------|
| Hyprland (primary) | `hypr/hyprland.lua` (Lua API, Hyprland 0.55+) | Noctalia / DMS |
| Niri | `niri/configs/*.kdl` | Noctalia / DMS |
| Sway | `sway/config` | Noctalia / DMS |
| FVWM3 (X11) | `fvwm/` (submodule) | tint2 |

Each Wayland compositor ships two keybind sets — `binds.noctalia.*` and
`binds.dms.*` — and Hyprland auto-selects at startup via `pcall(dofile, ...)`,
falling back to DMS if Noctalia is absent.

## Shell layer

- **Noctalia** (primary): desktop shell providing bar, launcher, notifications,
  OSD, lock screen, and a Material You theming pipeline. Config lives in
  `noctalia/settings.toml`.
- **DankMaterialShell** (fallback): the previous shell, kept for compatibility.

## Theming

Colors are generated by **Noctalia + matugen** (Material You): Noctalia renders
color templates into per-app config files on every wallpaper / theme refresh,
covering GTK, Qt, terminals (Kitty / Ghostty / Alacritty / Wezterm),
compositors, editors (Neovim, VSCode), and browsers. Driven from
`noctalia/settings.toml`.

Files **auto-generated by Noctalia** are gitignored because they change on
every refresh:

```
/hypr/noctalia.lua
/kitty/current-theme.conf
/kitty/themes/noctalia.conf
/niri/noctalia.kdl
/sway/noctalia
/fuzzel/themes/noctalia
```

Only source configs and hand-written templates are version-controlled.

## Repository layout

```
~/.config/
├── hypr/              Hyprland config (modular Lua: configs/, UserConfigs/, scripts/)
├── niri/              Niri config (modular configs/*.kdl)
├── sway/              Sway config + scripts
├── noctalia/          Noctalia settings.toml + user templates (sway-colors)
├── DankMaterialShell/ Fallback shell config
├── kitty/             Terminal config (theme injected by Noctalia)
├── ashell/            Rust-based Wayland status bar
├── fuzzel/            App launcher
├── fcitx5/            Input method
├── environment.d/     Session environment variables
├── starship.toml      Shell prompt (palette injected by Noctalia)
├── nvim/              → submodule: lazywalker/minivim
└── fvwm/              → submodule: lazywalker/fvwm
```

## Submodules

Two configs live in their own repositories and are linked as git submodules:

| Submodule | Path | Upstream |
|-----------|------|----------|
| minivim (Neovim) | `nvim/` | https://github.com/lazywalker/minivim |
| FVWM3 config | `fvwm/` | https://github.com/lazywalker/fvwm |

```bash
# Clone with submodules included
git clone --recurse-submodules <this-repo>

# Initialize submodules in an existing clone
git submodule update --init --recursive
```

## What is and isn't tracked

A whitelist `.gitignore` ignores everything at the root by default (`/*`) and
re-selectively allows specific directories/files. Only the configs worth
versioning are tracked; generated caches, session state, and per-machine tweaks
stay local.

## Requirements

- Arch Linux (uses `paru` as the AUR helper)
- Wayland session (Hyprland / Niri / Sway)
- `noctalia-git`, `hyprland`, `niri`, `sway`, `kitty`, `fuzzel`, `fcitx5`,
  `starship`, `paru`
- A Nerd Font (FantasqueSansM Nerd Font is the default across configs)

## Useful commands

```bash
# Hyprland: reload config
hyprctl reload

# Niri: screen transition (reloads config)
niri msg action do-screen-transition

# Update submodules to their latest upstream
git submodule update --remote --merge
```
